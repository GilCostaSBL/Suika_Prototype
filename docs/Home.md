# SuikaV2 — Vault Home

Open `docs/` as an Obsidian vault. Everything here is versioned with the code.

## Project goals
1. Recreate Suika Game in Godot 4.7, then add twists that make it more appealing.
2. Set up proper version control and documentation.
3. Understand the limits of Claude Code as a workflow tool (tracked in the [devlog](devlog/)).

## Map
- [Game Design Document](design/GDD.md)
- [Decisions](decisions/) — why we chose what we chose
- [Devlog](devlog/) — one note per session, including Claude Code observations
- [Templates](templates/)

## Conventions
- Markdown links with relative paths (no `[[wikilinks]]`) so notes render on GitHub.
- Screenshots go in `attachments/`.
- `docs/.gdignore` keeps Godot from importing anything in this folder.
