# SuikaV2

A Suika Game remake in Godot 4.7, with twists: player abilities (hold slot, purchasable swaps), gameplay modifiers, roguelite runs and extra modes.

## Getting started
1. Open `project.godot` in Godot 4.7.2 (standard build).
2. Press F5 to run.

## Documentation
Open `docs/` as an Obsidian vault and start at [docs/Home.md](docs/Home.md).
